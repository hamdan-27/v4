## Architecture

This is a Gatsby v3 static portfolio site for Hamdan Mohammad. The live URL is `https://hamdan.app`.

**Content** lives in `content/` as Markdown with frontmatter, sourced via `gatsby-source-filesystem`:

- `content/jobs/` — work experience entries (date, title, company, location, range, url + bullet points)
- `content/featured/` — highlighted projects with cover image (date ordering field, tech stack, github/external/cta links)
- `content/projects/` — other project cards (no images)
- `content/posts/` — blog posts, rendered via templates at `src/templates/post.js`

**Pages:**

- `src/pages/index.js` — single-page layout composing all section components in order: Hero → About → Jobs → Featured → Projects → Contact
- `src/pages/archive.js` — full projects list
- `src/pages/pensieve/` — blog index and tag pages
- `src/templates/` — post and tag page templates, generated by `gatsby-node.js`

**Components** at `src/components/`:

- Section components in `src/components/sections/` query their own data via `useStaticQuery`/GraphQL
- `layout.js` wraps all pages, handles the loading animation on home, external link attribution, and `ThemeProvider`
- Icons are individual SVG components under `src/components/icons/`

**Styling** uses styled-components with a global design token system:

- CSS custom properties defined in `src/styles/variables.js` (colors, font sizes, spacing, transitions)
- Reusable mixins in `src/styles/mixins.js`
- Theme breakpoints in `src/styles/theme.js` — always use `theme.bp.*` for media queries inside styled-components, raw pixel values in `@media` blocks elsewhere
- Primary font: Calibre (local), fallback to Inter/system-ui; mono: SF Mono/Fira Code

**Aliases** configured in `gatsby-node.js` — use `@components`, `@config`, `@fonts`, `@hooks`, `@images`, `@pages`, `@styles`, `@utils` instead of relative paths.

**Site config** (`src/config.js`) — update this file to change nav links, social media URLs, email, and ScrollReveal defaults.

**ScrollReveal** and **anime.js** are null-loaded during SSR (see `gatsby-node.js` webpack config) to avoid build-html errors — always wrap any DOM-dependent animation in a `usePrefersReducedMotion` guard or `useEffect`.

## Content Frontmatter Reference

**Jobs** (`content/jobs/<Company>/index.md`):

```yaml
date: 'YYYY-MM-DD'
title: 'Job Title'
company: 'Company Name'
location: 'City (Remote)'
range: 'Month YYYY - Month YYYY'
url: 'https://...'
```

**Featured projects** (`content/featured/<Name>/index.md`):

```yaml
date: '1' # numeric string controls display order (lower = first)
title: 'Project Name'
cover: './image.png'
github: 'https://...' # optional
external: 'https://...' # optional
cta: 'https://...' # optional second link
tech:
  - Tech 1
  - Tech 2
```
